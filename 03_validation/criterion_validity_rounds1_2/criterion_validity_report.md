# 效標效度檢驗報告 —— AI 可替代性量表（0–4）

> 日期：2026-07-25（第一輪，N=88）→ 2026-07-26（第二輪，N=320，設計修正版）。
> 對象：腿 B 的 AI 可替代性 rubric（`CLASSIFY_RUBRIC.md`）。
> 目的：補上此前缺失的**效標效度**——「可替代分」是否真的預測「AI 僅憑題幹答對的能力」。
> **結論（第二輪，最終）：效標效度確立。** rho=+0.22(可答對)/+0.42(充分度)，p<10⁻⁴，功效 0.98，穩健於「只用強參考答案」子集。第一輪（N=88）的零結果由功效不足（0.32）與入樣選擇偏誤共同解釋，診斷詳見下文，兩項均已在第二輪修正。

## 設計（三段盲態）

| 段 | 做法 | 執行者 |
|---|---|---|
| 抽樣 | 按可替代分分層隨機抽 python 問題，各檔 22 題（共 88），seed=20260725 | 本地腳本 |
| 真值 | 每題取 SO 上**被採納答案**，無則取**最高讚答案（≥1 讚）**，作人類真值 | SE API |
| 盲答 | LLM **僅看題目標題＋正文**作答，**不給可替代分、不給參考答案**，≤180 詞 | Claude Haiku 4.5（統一答題模型） |
| 盲判 | 獨立判分員對照人類真值判「是否真能解決」(0/1) 與「充分度」(1–5)，**不知可替代分** | Claude Opus（3 名，各判 28–30 題） |

判分標準明確要求嚴格：似是而非但未命中真因者計 answerable=0；泛泛「檢查版本／重裝」而參考答案指出具體病因者計 1–2 分。

## 結果（N = 88，各檔 22）

| 可替代檔 | n | AI 答對率 | 平均充分度(1–5) |
|---|---:|---:|---:|
| s1（最不可替代） | 22 | **0.41** | 3.23 |
| s2 | 22 | 0.41 | 2.82 |
| s3 | 22 | 0.55 | 3.14 |
| s4（最可替代） | 22 | **0.59** | 3.23 |

**檢驗：**

| 檢驗 | 結果 |
|---|---|
| Spearman(分, 答對) | rho = **+0.152**, p = .156 |
| Spearman(分, 充分度) | rho = +0.034, p = .754 |
| 生成型(s3-4) vs 驗證型(s1-2) 答對率 | **0.568 vs 0.409（+15.9pp）**, OR = 2.09 |
| 端點 s4 vs s1 | 0.59 vs 0.41, Fisher 單側 p = .183 |
| Logit 答對 ~ 分 | coef = +0.276, p = .155 |

**裁定：方向一致，但在 α=.05 下效標效度「未確立」。**

## 兩項關鍵診斷（決定如何解讀這個零結果）

**1. 嚴重功效不足。** 生成型 vs 驗證型的差是 15.9 個百分點、OR≈2.1，屬有意義的效應量；但 Cohen's h = 0.320，**當前功效僅 0.32**。達 80% 功效需**每組 n≈154（總計約 307 題）**。即：本檢驗在 N=88 時，即使效應為真也有約 2/3 概率測不出。**這是「不確定」，不是「否證」。**

**2. 入樣選擇偏誤，方向對本檢驗不利。** 入樣要求該題有「被採納或高讚答案」（否則無人類真值）。但各檔的入樣率差異極大：

| 檔 | 每 70 個候選中有可信人類答案者 |
|---|---|
| s1 | 8（11%） |
| s2 | 13（19%） |
| s3 | 14（20%） |
| s4 | ≥22（31%+） |

即：**驗證型問題本就更難獲得優質人類答案**（這本身佐證論文機制）。後果是入樣的 s1 是「異常好答」的驗證型問題，**該選擇朝削弱梯度的方向偏**，故本檢驗偏保守，真實梯度應大於觀測值。

## 誠實結論

- 效標效度**尚未確立**（p = .16），但**方向一致、效應量非微小（OR≈2.1）**，且受兩項可識別因素削弱（功效 0.32、入樣選擇對假設不利）。
- 充分度（1–5）**完全沒有梯度**（rho=.03）而二元答對率有——說明該量表若有效度，是關於「**能否解決**」而非「**答得多好**」。
- 對論文的含義：站內剂量反應的**經驗事實不受影響**（高分題在 ChatGPT 後降更多是實測結果）；受影響的是其**機制解釋**（「因為 AI 能答」）——目前該解釋有方向性但非決定性的效標支持，須如實寫入局限。

## 第二輪（N=320，2026-07-26）：設計修正 + 擴樣

### 兩項修正
1. **放寬真值定義**：不再要求「有優質答案」才入樣；改為對每題的最佳可得答案分級（accepted > top_voted > weak > none），把品質告知判分員但不用來篩選樣本。
2. **擴樣至每檔 80（共 320）**：達到第一輪功效分析算出的 154/組門檻（本設計為 160/組）。
3. **答題模型改為 Sonnet 5**（原 Haiku 4.5）：更貼合 rubric 原文「a capable model」與原始分類器（Sonnet4.6/Opus4.8）的能力層級,修正了第一輪的一個構念效度瑕疵。判分維持 Opus（本輪 Opus 5），並新增對 reference_quality="none" 題目的直判規則（無人類答案時，判分員僅憑技術專業判斷 AI 解法是否合理可行）。

### 選擇偏誤診斷坐實（現在是無條件抽樣下的真實比例）

| 檔 | 無參考答案 | 弱參考 | 高讚 | 被採納 |
|---|---|---|---|---|
| s1 | 29% | 29% | 24% | 19% |
| s2 | 26% | 15% | 25% | 34% |
| s3 | 11% | 15% | 28% | 46% |
| s4 | 6% | 10% | 36% | 48% |

驗證型問題（s1）近三成完全沒有人類答案，生成型（s4）僅 6%——第一輪的診斷成立，且方向確如預期會使檢驗趨於保守。

### 結果（N=320，各檔 80）

| 檔 | AI 答對率 | 平均充分度 |
|---|---:|---:|
| s1 | 0.787 | 3.71 |
| s2 | 0.825 | 4.08 |
| s3 | 0.938 | 4.45 |
| s4 | 0.963 | 4.59 |

| 檢驗 | 結果 |
|---|---|
| Spearman(分, 答對) | rho = **+0.218**, p = **8.5×10⁻⁵** |
| Spearman(分, 充分度) | rho = **+0.420**, p = **4.4×10⁻¹⁵** |
| 生成型(s3-4) vs 驗證型(s1-2) | **0.950 vs 0.806（+14.4pp）**, OR = 4.57, Fisher p = 5.9×10⁻⁵ |
| 端點 s4 vs s1 | 0.963 vs 0.787, Fisher p = 6.6×10⁻⁴ |
| OLS 充分度~分 | 斜率 +0.300/點, p = 6.5×10⁻¹⁵ |
| Logit 答對~分 | OR/點 = 1.92, p = 2.0×10⁻⁴ |
| **實現功效**（Cohen's h=0.461） | **0.98**（設計目標 0.80） |

**裁定：效標效度確立。** 方向一致、統計顯著、功效充足。

### 穩健性

- **限縮到強參考子集（accepted+top_voted, N=207，最接近第一輪隱含的篩選標準）**：rho(答對)=+0.285, p=3.1×10⁻⁵；生成 93.7% vs 驗證 75.3%。**結果不是靠納入弱/無參考題撐起來的**，在最嚴格子集下依然成立。
- **僅 reference_quality=none 子集（N=58，純判分員專業判斷，無人類答案錨定）**：rho=+0.061, p=.65，不顯著；但此子集本身樣本小且分佈不均（23/21/9/5），且方向仍一致（s1/s2 合計 86% vs s3/s4 合計接近 100%）。不足以單獨定論,但也不與主結果矛盾。
- **與第一輪對照**：第一輪 rho=+0.034（p=.75, N=88, 生成 56.8% vs 驗證 40.9%）；第二輪 rho=+0.420（N=320, 生成 95.0% vs 驗證 80.6%）。絕對答對率大幅上升主要應歸因於**答題模型從 Haiku4.5 換成 Sonnet5**（更強模型、更貼合 rubric 定義的「capable」），而非樣本本身變化；但更重要的是**梯度本身從無到有、且高度顯著**——這才是效標效度的核心主張。

### 誠實結論（取代第一輪版本）

- 效標效度**已確立**：AI 可替代分能顯著預測「AI 是否真能僅憑題幹答對」，且該關係在充分度（連續量尺）與二元答對率上都成立，穩健於參考答案品質的嚴格篩選。
- 對論文的含義：站內剂量反應的機制解釋（「因為 AI 能答」）**現在有決定性的效標支持**，此前「方向性、非決定性」的措辪應予升級。
- 唯一保留的細節：純無參考子集（N=58）單獨看不顯著，這在報告穩健性時應如實提及，但不影響主結論（該子集是全樣本的一個小穩健性切片，非獨立檢驗）。
