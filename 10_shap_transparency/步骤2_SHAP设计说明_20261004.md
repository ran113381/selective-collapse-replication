## 1. 要回答的问题，和不回答的问题

**问题**：盲分类器（Claude Sonnet 5）给 python 6,000 题打的 0–4 分，能不能用题面上看得见的表层特征近似出来？如果能，这些分数主要落在量表档位描述的五个属性上，还是落在别的东西上（话题标签、长度）？方向与量表写的是否一致？

这是对审稿疑问「可替代度完全靠大模型打分，会不会有模型自身偏见」的一项透明度检验：它说明分类器的分数**跟着什么走**。

**不回答**：
- 不解释崩塌的原因。SHAP 解释的是一个替代模型，不是平台行为。
- 不证明量表有效。效度靠 §6.3 的效标、人工编码员和版主。
- 不独立于大模型。替代模型是照着大模型的标签训练的。
- **不用替代模型的预测分重估 γ。** 这是对改稿计划第 5 节的偏离，理由有两条。第一，替代分是大模型标签的函数，不构成独立证据。第二，特征里有随时期漂移的量（长度，§7.5 已报各档提问变长 1.2–1.3 倍）。用它重估 γ，会把 §7.5 的「润色重标」对手混进来，而这里又分不开。所以不算，也就不存在「算了不报」。

## 3. 文本与特征（固定，不调）

文本 `T = title + "\n" + body`。正则一律不区分大小写（F11 例外：只对 title 匹配）。「计数」= 非重叠匹配次数。词 = `\S+`。
表格单元里的 `\|` 是 markdown 转义，写进 Python 正则时就是 `|`（例如 F08 的开头在代码里是 `r"[A-Za-z]:\\|/(home|usr|var|etc|opt|Users)/|..."`）。执行脚本须把每条正则原样写进 `shap_result.json` 的 `feature_spec`，第 6 步复核据此逐条对本表。

## 4. 模型（固定超参，不做任何搜索）

- `lightgbm.LGBMRegressor(objective="regression", n_estimators=400, learning_rate=0.05, num_leaves=15, min_child_samples=40, subsample=0.8, subsample_freq=1, colsample_bytree=0.8, reg_lambda=1.0, random_state=20261004, n_jobs=1, deterministic=True, force_row_wise=True, verbose=-1)`
- 目标 = 0–4 分（含 s0，全部 6,000 题）。
- `sklearn.model_selection.KFold(n_splits=5, shuffle=True, random_state=20261004)`；每折训练，对留出折预测并算 `shap.TreeExplainer(model).shap_values(X_holdout)` → 得到全部 6,000 题的折外预测与折外 SHAP 矩阵（6,000 × 29）。
- 确定性自证：整套流程跑两遍，折外预测与 SHAP 矩阵的 sha256 两遍必须相同，否则停止。
- 结果 JSON 记录 python、lightgbm、shap、sklearn、numpy 的版本。

## 5. 预先登记的判据

| 编号 | 量 | 计算 | 判据 |
|---|---|---|---|
| C1 拟合度（停止规则） | 折外 AUC | 用折外连续预测区分 生成类（score ≥ 3）与 验证类（score ≤ 2），`roc_auc_score` | **AUC < 0.65：停**。不出图，正文只写一句（第 4 步任务书给句式）。另报折外 Spearman ρ（预测 vs 分数），不设门槛 |
| C2 属性占比 | 五个属性组特征的 mean\|SHAP\| 之和 ÷ 全部 29 个特征的 mean\|SHAP\| 之和 | 一个比例 | ≥ 0.50 记为「分数主要落在量表属性上」，否则如实写「主要落在话题/其他上」 |
| C3 方向一致 | 16 个有方向的特征里，mean\|SHAP\| ≥ 全部 29 个特征中位数的那些；逐个算 Spearman ρ(特征值, 该特征的 SHAP 值)，符号与预设方向相同记一致；ρ 为 0 或无定义记不一致 | 一致个数 / 入选个数 | ≥ 2/3 记为「方向与量表一致」，否则如实写哪几个相反 |
| R1 去长度稳健性 | 去掉 F01、F02 重拟合，同一折、同一超参 | 重报 C1、C2、C3 | 只报不判 |
| S1 前后期稳定性（次要） | 用 `R2_ym_map.json` 把折外 SHAP 按事件前（ym < 2022-12）/后分两组，各算 29 维 mean\|SHAP\| 向量，取两向量的 Spearman ρ | 一个数 | 只报不判 |

逐特征一律报：mean\|SHAP\|、排名、所属组、预设方向、ρ(特征值, SHAP)、是否一致。

结果好坏都报。C2、C3 任一不达，正文照写，不换判据、不换特征、不调超参。
